# Segurança

## Privacidade

A ferramenta não possui funcionalidade de rede própria e não envia fotos, vídeos, nomes de arquivos ou informações do aparelho para serviços externos. O ADB estabelece a comunicação local por USB com o dispositivo autorizado.

## Recomendações

- Obtenha o projeto somente deste repositório ou de uma distribuição confiável.
- Confira os arquivos copiados antes de excluir qualquer conteúdo do celular.
- Desative a Depuração USB após concluir o backup.
- Revogue autorizações antigas nas Opções do desenvolvedor quando o computador não for mais confiável.
- Não mantenha o celular desbloqueado e conectado a computadores desconhecidos.

## Relato de vulnerabilidades

Não publique dados pessoais, registros contendo nomes de arquivos privados ou detalhes do aparelho em uma issue pública. Use o recurso privado **Report a vulnerability** do GitHub, quando disponível no repositório.

Inclua uma descrição do problema, a versão do Windows e do Android e passos mínimos para reprodução, removendo previamente informações pessoais.
